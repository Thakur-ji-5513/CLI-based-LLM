# 🤖 CLI Based LLM

Hey people! 👋

This is a project I built to deepen my understanding of Python 🐍. I developed it using WSL and VS Code 💻. It runs locally on your machine and can assist your workflow like a small agent capable of performing CRUD operations on directories you specify, using Gemini under the hood ✨.

> [!NOTE]
> ⚠️ What I've built is a toy version of something like Cursor/Zed's Agentic Mode or Claude Code.
>
> Even those tools aren't perfectly secure, so be careful what you grant access to 🔒. This project is intended purely for learning purposes and experimentation 🧪.

## 🚀 How to Use It Locally

1. 🍴 Fork and clone the repository.
2. 🔑 Obtain your own Gemini API key and save it in a `.env` file in the project's root directory.
3. 📂 Open the project directory in a terminal.
4. ▶️ Run:

   ```bash
   uv run main.py
   ```
5. ⏳ Wait a few seconds while the AI processes your request.
